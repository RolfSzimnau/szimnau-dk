**Update, November 2026:** Home Assistant 2026.11 hat die alte Aktion `notify.android_tv_*` als veraltet markiert, ab Version 2027.5 funktioniert sie nicht mehr. Deshalb nutzt das TV-Beispiel jetzt `nfandroidtv.send_message`. Auch der Rest des Beitrags ist korrigiert und passt zu meinem heutigen Setup: Diese Änderungen haben nichts mit der neuen Version zu tun. Außerdem speichert die Automatisierung kein Standbild mehr unter `/local`, denn Dateien dort lassen sich ohne Anmeldung abrufen.

Die ersten zwei Wochen nach der Installation der Sentinel-Kamera hatte ich Bewegungsbenachrichtigungen aktiviert. Jede einzelne sagte "Bewegung erkannt." Vögel, Schatten, eine Plastiktüte, die nachts um drei an der Linse vorbeiwehte. Ich schaltete alle aus und ließ die Kamera für einen weiteren Monat nutzlos herumstehen.

Die Lösung war einfacher als erwartet: nur bei Personen und Fahrzeugen auslösen (nicht bei roher Bewegungserkennung) und der Benachrichtigung drei Schaltflächen geben, die tatsächlich etwas tun.

## Was die Integration bietet

Nach dem Hinzufügen der Kamera erstellt HA mehrere binäre Sensoren aus der integrierten Erkennung:

```
binary_sensor.sentinel_motion
binary_sensor.sentinel_person
binary_sensor.sentinel_animal
binary_sensor.sentinel_vehicle
```

Personen- und Fahrzeugerkennung kommen vom KI-Chip der Kamera. Ziemlich präzise: besser als reine Bewegungserkennung, aber nicht fehlerfrei. Der Tiersensor hat echte Füchse erkannt und unvergessen auch eine große Plastiktüte, die sich auf eine Weise bewegte, die offenbar lebendig wirkte.

## Eine Automatisierung für beide Auslöser

Personen- und Fahrzeugereignisse laufen durch eine einzige Automatisierung im `parallel`-Modus, sodass eine Person und ein Auto gleichzeitig je eine Meldung auslösen können. Jeder Typ hat seine eigene Sperrzeit: Der Zeitpunkt der letzten Meldung landet in einem `input_datetime`, und die Template-Bedingung verwirft alles, was innerhalb von 60 Sekunden kommt.

```yaml
alias: "Sentinel: Kamera & Benachrichtigung"
mode: parallel
max_exceeded: silent
trigger:
  - platform: state
    entity_id: binary_sensor.sentinel_person
    from: "off"
    to: "on"
    id: person
  - platform: state
    entity_id: binary_sensor.sentinel_vehicle
    from: "off"
    to: "on"
    id: fahrzeug
variables:
  notif_title: "{{ '\U0001F697 Fahrzeug an der Einfahrt' if trigger.id == 'fahrzeug' else '\U0001F464 Person an der Einfahrt' }}"
  notif_message: "{{ 'Sentinel hat ein Fahrzeug erkannt' if trigger.id == 'fahrzeug' else 'Sentinel hat eine Person erkannt' }}"
  cooldown_entity: "{{ 'input_datetime.sentinel_last_vehicle_notification' if trigger.id == 'fahrzeug' else 'input_datetime.sentinel_last_person_notification' }}"
condition:
  - condition: state
    entity_id: input_boolean.sentinel_notifikation_lydlos
    state: "off"
  - condition: template
    value_template: >-
      {% set last = states(cooldown_entity) %}
      {% if last in ['unknown', 'unavailable', ''] %}
        true
      {% else %}
        {{ (now().timestamp() - as_timestamp(last, 0)) > 60 }}
      {% endif %}
action:
  - action: notify.mobile_app_pixel_10
    data:
      title: "{{ notif_title }}"
      message: "{{ notif_message }}"
      data:
        ttl: 0
        priority: high
        channel: Sicherheit
        importance: high
        tag: sentinel_alert
        image: /api/camera_proxy/camera.sentinel_snapshots_clear
        actions:
          - action: URI
            title: Kamera anzeigen
            uri: homeassistant://navigate/nyt-mobil/overvagning
          - action: sentinel_flood_on
            title: Flutlicht einschalten
          - action: sentinel_mute_30
            title: 30 Min. stumm
        clickAction: /nyt-mobil/overvagning
  # derselbe Aufruf geht an die beiden anderen Geräte
  # hier folgt der TV-Schritt, siehe unten
  - action: input_datetime.set_datetime
    target:
      entity_id: "{{ cooldown_entity }}"
    data:
      datetime: "{{ now().strftime('%Y-%m-%d %H:%M:%S') }}"
```

Zwei Telefone und ein Tablet bekommen je einen Aufruf mit demselben Inhalt: ein Standbild von `camera.sentinel_snapshots_clear` und drei Schaltflächen.

## Der Stummschalten-Schalter

Die erste Bedingung ist `input_boolean.sentinel_notifikation_lydlos` (Benachrichtigung stumm) mit dem Zustand `off`. Das ist einfacher als eine `armed_away`-Bedingung: Es braucht keine Alarmzentrale, es funktioniert unabhängig davon, ob man zu Hause ist oder nicht, und die Benachrichtigung selbst kann den Schalter über die Stumm-Schaltfläche einschalten.

Eine separate Automatisierung schaltet ihn nach 30 Minuten wieder aus, sodass ich nie daran denken muss.

## Aktionsschaltflächen

Die Benachrichtigung hat drei Schaltflächen:

- **Kamera anzeigen**: Deep-Link zur Sicherheitsansicht in der HA-Companion-App
- **Flutlicht einschalten**: schaltet `light.sentinel_floodlight` über eine separate Automatisierung ein, die auf das `sentinel_flood_on`-Ereignis vom Telefon hört
- **30 Min. stumm**: schaltet den Stummschalter über dieselbe Automatisierung ein, und das Zurücksetzen unten schaltet ihn nach 30 Minuten wieder aus

Die Stumm-Schaltfläche schaltet den Schalter nur ein. Das Zurücksetzen ist eine eigene Automatisierung und greift deshalb auch, wenn der Schalter auf andere Weise eingeschaltet wird:

```yaml
alias: "Sentinel: Stummschaltung zurücksetzen"
trigger:
  - platform: state
    entity_id: input_boolean.sentinel_notifikation_lydlos
    to: "on"
action:
  - delay:
      minutes: 30
  - action: input_boolean.turn_off
    target:
      entity_id: input_boolean.sentinel_notifikation_lydlos
```

## Fire TV-Benachrichtigung

Dieselbe Automatisierung sendet auch an den Fernseher im Wohnzimmer:

```yaml
  - action: nfandroidtv.send_message
    continue_on_error: true
    target:
      entity_id: notify.android_tv_fire_tv_192_168_1_40
    data:
      message: "{{ '\U0001F697 Fahrzeug an der Einfahrt erkannt' if trigger.id == 'fahrzeug' else '\U0001F464 Person draußen erkannt' }}"
      image:
        media_content_id: media-source://camera/camera.sentinel_fluent
        media_content_type: image/jpeg
      interactive: true
```

HA holt selbst ein frisches Bild von der Kamera und schickt das Bild direkt an den Fernseher. Es gibt also keine URL und kein altes Bild aus dem Cache. `interactive: true` lässt es auch während der Wiedergabe erscheinen. `continue_on_error: true` muss bleiben: Ohne den Parameter stoppt ein ausgeschalteter Fernseher die Automatisierung, und die folgenden Schritte laufen nicht mehr.

## Das Dashboard

Die Sicherheitsansicht zeigt oben die Kamera, dann Status-Chips für Bewegung, Person, Tier und Fahrzeug und eine Liste der letzten Ereignisse. Die Chips folgen alle demselben Muster:

```yaml
type: custom:mushroom-chips-card
chips:
  - type: template
    entity: binary_sensor.sentinel_person
    icon: mdi:walk
    icon_color: "{% if is_state('binary_sensor.sentinel_person','on') %}orange{% else %}disabled{% endif %}"
    content: Person
    tap_action:
      action: more-info
```

Eine kleine Automatisierung führt die Liste und setzt jedes neue Ereignis an den Anfang eines `input_text`:

```yaml
alias: Sentinel event log
mode: queued
max: 10
trigger:
  - trigger: state
    entity_id: binary_sensor.sentinel_person
    to: "on"
    id: person
  - trigger: state
    entity_id: binary_sensor.sentinel_motion
    to: "on"
    id: motion
  - trigger: state
    entity_id: binary_sensor.sentinel_animal
    to: "on"
    id: animal
  - trigger: state
    entity_id: binary_sensor.sentinel_vehicle
    to: "on"
    id: vehicle
action:
  - action: input_text.set_value
    target:
      entity_id: input_text.sentinel_event_log
    data:
      value: >-
        {% set m = {'person':'👤 Person','motion':'🏃 Motion','animal':'🐾 Animal','vehicle':'🚗 Vehicle'} %}
        {% set new = now().strftime('%H:%M') ~ ' ' ~ m[trigger.id] %}
        {% set old = states('input_text.sentinel_event_log') %}
        {% set items = ([new] + (old.split(' · ') if old not in ['unknown','unavailable',''] else []))[:10] %}
        {{ (items | join(' · '))[:255] }}
```

Die Liste enthält die letzten zehn Ereignisse, und Bewegung zählt mit, also verdrängt ein unruhiger Nachmittag den Vormittag. Die Grenze von 255 Zeichen kommt von `input_text` selbst.
